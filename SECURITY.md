# Security Policy

## Supported versions

Security fixes are made against the latest `0.x` release. Older releases are not patched.

## Reporting a vulnerability

Please report vulnerabilities privately by email to **xertz@alos.gg**. Do not open a public issue or pull request for a security problem.

Include as much of the following as you can:

- the alos-http version or commit you tested
- the platform (kernel version, Go version) and relevant `core.Config` settings
- a minimal reproduction (raw request bytes, client program, or test case)
- the impact you observed or expect (crash, memory growth, data exposure, bypass, etc.)

You will get a reply to your report. Please keep the details private until a fix has been released.
